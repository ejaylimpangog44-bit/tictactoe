# Tic-Tac-Toe: Player vs AI

## About the Project
Tic-Tac-Toe is a simple web-based game built using HTML, CSS, and JavaScript. Players use X to compete against an AI opponent that uses O.

## Features
- Player vs AI gameplay
- Three difficulty levels: Easy, Normal, and Hard
- Interactive 3×3 game board
- Automatic win, lose, and draw detection
- Play Again option
- Responsive user interface

## Technologies Used
- HTML — webpage structure
- CSS — design and layout
- JavaScript — game logic and AI

## How to Play
1. Open the game in your web browser.
2. Select your preferred difficulty.
3. Click an empty square to place X.
4. The AI will respond with O.
5. Get three matching symbols in a row to win.
6. Choose whether to play again.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
